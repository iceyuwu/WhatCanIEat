## 技术框架介绍

> 2min

Vue.js + SpringBoot + SpringMVC + MaBatisPlus +MySql 

***MVC架构***

***前后端分离***

***B/S架构***



讲：

项目基于 **Vue.js + Spring Boot** 的前后端分离 Web 项目，采用经典 **MVC 架构** 与 **B/S（Browser/Server）架构** 设计。

前端使用 Vue.js框架，能够简单快捷地实现使用体验优秀的前端界面。后端基于 Spring Boot 整合 Spring MVC 负责请求分发与接口设计，结合 MyBatis-Plus 完成数据库层操作，使用 MySQL 数据库作为数据存储。，实现前后端分离。

系统前后端通过Restful风格交互（就是Json格式），实现了前后端职责解耦，前端专注展示与交互，后端专注业务逻辑与数据处理，具备良好的扩展性与维护性。

## 前端实现

> 1min 



***单页面应用 SPA（Single Page Application）***

- 整个网站**只有一个 HTML 页面**
- 页面内容通过 JavaScript 动态更新
- 页面切换不刷新浏览器

***组件化设计（Component-based Architecture）***

- 把 UI 拆成一个个**独立、可复用的小模块**
- 由 Vue Router 提供路由

优点：提升可维护性、提高复用性、降低复杂度

讲：

前端通过 Vue.js 的单页面应用（SPA）和组件化设计思想实现。将整体应用按照功能模块拆分为多个独立的 Vue 组件，每个组件负责自身的结构、样式与逻辑。

再借助 Vue Router 实现前端路由控制，根据不同的 URL 动态加载对应的页面组件，在无需刷新页面的情况下完成视图切换，提升用户体验。通过组件的嵌套与组合，可以灵活构建出各种界面。



## 后端实现

> 1min
>
> 快速介绍Controller层、Service层、Dao层

***MVC架构***

controller层（控制器层）

Service层（业务层）

Dao层（Data Access Object 数据访问层）

讲：

在 Spring Boot 的后端开发中，通常采用分层架构来组织代码，其中 **Controller、Service、Dao（或 Mapper）** 是最核心的三层，各自职责清晰，协同完成业务处理。

**Controller 层负责接收请求 + 返回响应：**

- 接收前端（如 Vue.js）发送的请求 
- 解析请求参数（路径参数、请求体等）
- 调用 Service 层处理业务
- 将结果封装为 JSON 返回给前端

**Service 层负责核心业务逻辑处理：**

- 编写具体业务逻辑（比如登录、注册、查询菜谱等）
- 调用 DAO 层保存/查询/处理数据

**Dao 层直接操作数据库**

- 与 MySQL 交互
- 执行 CRUD（增删改查）
- 将数据库的数据映射为 Java 对象
